# Butterflyc

انشاء لي تطبيق دردشة عامه للجميع باسم شات فراشات العرب التسجيل عن طريق صورة مستخدم واسم وكلمه سر والحاله والجنس والعمر فقط ويدعم العربي بجميع الزخرفات والنصوص وايضا الدخول عن طريق الاسم وكلمه السر فقط لا يوجد توثيق ولا يوجد تصريح ويمنع اضافه بريد الكتروني او رقم هاتف او دخول عن طريق جوجل نهائيا وبعد التسجيل تفتح قائمه عامه تحتوي على عده غرف دردشه 5 غرف الغرفه صورة واسم ووصف وبالقائمه السفليه يوجد الرئيسية والمتصلين والخاص والملف الشخصي ويكون تصميم احترافي باستخدام اقوى واحدث التقنيات والتركيز على جعل كل شي احترافي والرسومات SVG وايضا اول حساب يتم انشائه يتم حفظه كحساب مالك التطبيق ويتم اضافه لوحه تحكم ادارية كامله تتحكم في كل شي الاعضاء والغرف والرسائل والخاص ويتم تعين مشرف لغرفه او للتطبيق او مشرف لقسم محدد يوجد كل الصلاحيات لي كمالك للتطبيق
